# Commercial Real Estate & Financing Blueprint Landing Page

Static landing page prepared for GitHub and Netlify.

## Deploy on GitHub + Netlify
1. Create a new GitHub repository.
2. Upload every file and the `assets` folder from this project.
3. In Netlify, choose **Add new site → Import an existing project**.
4. Connect GitHub and select the repository.
5. Leave the build command blank and set the publish directory to `.`.
6. Deploy the site.

The registration form is configured for Netlify Forms and redirects to `thank-you.html`.
