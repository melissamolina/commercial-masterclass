# Next Level Commercial Masterclass — Black & Red Edition

## Important: upload every file together
This package is intentionally flat. Do not rename or separate the images.

Upload these files to the ROOT of your GitHub repository:

- index.html
- styles.css
- script.js
- thank-you.html
- netlify.toml
- next-level-logo.jpg
- spartan-logo.png

The image paths are already set to:

- ./next-level-logo.jpg
- ./spartan-logo.png

## Netlify
Import the GitHub repository into Netlify. No build command is needed. Publish directory: `.`

After deployment, test the form once. Registrations should appear under Netlify → Forms.
